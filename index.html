📱 Установить «Пинток Медикал» на телефон как приложение

Мобильное приложение «Пинток Медикал»

Работает без адресной строки, на полный экран, со всеми филиалами и ИИ-помощником Antigravity!

🤖 Android (Chrome, Samsung)
  1. Откройте сайт в Google Chrome на телефоне.
  2. Нажмите на три точки вверху (⋮).
  3. Выберите пункт «Установить приложение» (или «Добавить на главный экран»).
  4. Иконка появится на рабочем столе смартфона!
🍏 iPhone (Safari)
  1. Откройте ссылку в браузере Safari.
  2. Нажмите внизу кнопку «Поделиться» (квадрат со стрелкой вверх ⬆️).
  3. Пролистайте вниз и выберите «На экран «Домой»».
  4. Готово! Приложение установлено на iPhone.

Запустите файл запустить_для_телефона.bat на компьютере и откройте в браузере телефона адрес:
